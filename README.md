# 🖧 Projeto de Redes

Este repositório tem como objetivo registrar meu aprendizado prático em **Protocolos de Redes de Computadores**, utilizando o Cisco Packet Tracer.

## 🎯 Objetivo
Consolidar conhecimentos em redes por meio de laboratórios práticos, simulando cenários reais de configuração e troubleshooting.

## 🛠️ Tecnologias e Ferramentas
- Cisco Packet Tracer
- Redes TCP/IP
- Conceitos de Infraestrutura de Redes

## 🚀 Evolução
Este repositório será atualizado conforme avanço nos estudos, incluindo novos protocolos, testes e cenários mais complexos.

## 📌 Observação
Este é um projeto de estudo, desenvolvido com foco em aprendizado prático e evolução contínua na área de redes.
